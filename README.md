# FrontEnd Store

Tienda de camisetas con carrito de compras, API en Node.js y PostgreSQL para guardar pedidos.

## Ejecutar localmente

Consulta [CONFIGURACION-POSTGRESQL.md](CONFIGURACION-POSTGRESQL.md) para preparar PostgreSQL, iniciar la API y abrir la tienda.

## Publicar en Internet

La guía de configuración incluye los pasos para publicar el frontend en Netlify, la API en Render y la base de datos en Neon.

No publiques contraseñas ni archivos `.env`.
